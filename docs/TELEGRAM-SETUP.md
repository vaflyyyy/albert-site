# Telegram: уведомления и кнопки подтверждения

## 1. Бот и ID
1. В Telegram откройте **@BotFather** → `/newbot` → получите токен → `TELEGRAM_BOT_TOKEN`.
2. Откройте своего бота и нажмите **Start**.
3. Узнайте свои ID: временно запустите `npm run telegram:poll` и отправьте боту команду **/id** — он ответит вашим Telegram ID и ID чата.
   (Для личного чата они совпадают.) Впишите в `.env.local`:

```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=ваш_id_чата
TELEGRAM_ADMIN_IDS=ваш_telegram_id      # через запятую, если админов несколько
TELEGRAM_WEBHOOK_SECRET=длинная_случайная_строка   # openssl rand -hex 24
NEXT_PUBLIC_SITE_URL=https://ваш-домен
```

Если заявки идут в **группу** (chat id отрицательный), `TELEGRAM_ADMIN_IDS` обязателен: кнопки сработают только у перечисленных людей.

## 2. Проверка связи
```bash
npm run telegram:test
```

## 3. Как получать нажатия кнопок
**Локально (без публичного адреса):**
```bash
npm run dev
npm run telegram:poll     # во втором окне терминала
```
**Продакшен (https-адрес сайта):**
```bash
npm run telegram:webhook -- set     # установить
npm run telegram:webhook -- info    # проверить
npm run telegram:webhook -- delete  # снять
```
Режимы polling и webhook взаимоисключающие: `telegram:poll` снимает вебхук, после разработки снова выполните `-- set`.

## 4. Проверочный сценарий
1. Отправьте заявку на сайте → в Telegram придёт сообщение с тремя кнопками, на сайте — номер записи и ссылка на статус.
2. Нажмите **Подтвердить** → сообщение обновится («✅ Запись подтверждена»), страница статуса клиента сменится сама в течение ~5 секунд.
3. **Отклонить** → статус «Запись отклонена».
4. **Предложить другое время** → бот попросит ответить на сообщение; ваш текст появится на странице клиента.
5. Нажатие кнопки чужим аккаунтом → «У вас нет прав», статус не меняется.

Если токен случайно попал в чат или репозиторий — в @BotFather выполните `/revoke` и обновите `.env.local`.
