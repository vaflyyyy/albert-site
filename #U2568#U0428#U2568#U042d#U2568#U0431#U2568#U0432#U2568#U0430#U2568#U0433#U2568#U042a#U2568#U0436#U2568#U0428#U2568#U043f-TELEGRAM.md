# Подключение Telegram-уведомлений — простая инструкция

## 1. Куда вставить токен и Chat ID

В корне проекта создайте файл **`.env.local`** (скопируйте `.env.example`):

```bash
cp .env.example .env.local
```

Откройте `.env.local` и заполните две строки (без кавычек и пробелов):

```
TELEGRAM_BOT_TOKEN=сюда_токен_от_BotFather
TELEGRAM_CHAT_ID=сюда_ваш_chat_id
```

- Токен выдаёт @BotFather (вид: `123456789:AA...`).
- Chat ID — число (для личного чата обычно положительное, для группы — с минусом).
- **Важно:** откройте своего бота в Telegram и нажмите **Start** (или отправьте `/start`). Пока вы этого не сделали, бот не сможет вам писать.
- Файл `.env.local` не попадает в git. Не отправляйте токен в чаты и не коммитьте его.
  Если токен случайно «утёк», в @BotFather выполните `/revoke` и вставьте новый.

## 2. Как запустить сайт

```bash
npm install          # один раз
npm run dev          # откройте http://localhost:3000
```

После любого изменения `.env.local` **перезапустите** `npm run dev`.

## 3. Проверить связь с Telegram (до запуска сайта)

```bash
npm run telegram:test
```

Скрипт проверит токен, найдёт бота и пришлёт вам тестовое сообщение. Если что-то не так, он подскажет, что именно.

## 4. Как это работает на сайте

1. Клиент заполняет форму на `/contact` и нажимает «Отправить заявку».
2. Браузер отправляет данные на ваш сервер (`/api/bookings`). Токена в браузере нет — он читается только на сервере.
3. Сервер проверяет поля и отправляет вам в Telegram: имя, телефон, услугу, дату, время, способ связи и комментарий.
4. Только если Telegram принял сообщение, клиент видит «Заявка отправлена». Даже тогда текст честно говорит, что запись подтверждается после вашего ответа.
5. Если что-то пошло не так, клиент видит понятную ошибку, а не ложное подтверждение:
   - Telegram не настроен → «Онлайн-отправка заявок пока не подключена, заявка не отправлена».
   - Telegram не принял сообщение или нет связи → «Не удалось отправить заявку…».
   - Поля заполнены неверно → ошибки подсвечиваются у полей.
   - Слишком много попыток подряд → просьба подождать.

## 5. Публикация на хостинге

Добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в переменные окружения хостинга (Vercel: Project Settings → Environment Variables), затем сделайте redeploy. Файл `.env.local` на хостинг загружать не нужно.
